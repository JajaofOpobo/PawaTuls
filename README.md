# PawaTuls
Microsoft Word task pane add-in called "PawaTuls".  Stack: Office.js (WordApi 1.5 minimum), React 18, TypeScript 5, Fluent UI v9. Platform: Windows, Word for Microsoft 365 desktop only. Project root: chambers-word-toolkit/  The add-in has three feature areas:   1. Full Formatting Engine — font, paragraph, styles, text transforms, conversions, etc.
